Scan all .cls files in the main RenderDraw package classes directory.

**Step 1 — Classify classes:**
For each .cls file, read the class declaration line to determine:
- Visibility: `global` vs `public` vs `private`
- Sharing: `with sharing` vs `without sharing` vs none
- Type: regular class, test class (@isTest), interface, enum
- Skip test classes entirely (not public API)

**Step 2 — Extract public methods from global and public classes:**
For each non-test global/public class:
1. Extract all methods annotated with `@AuraEnabled`, `@InvocableMethod`, `@RemoteAction`, `@HttpGet/@HttpPost/@HttpPut/@HttpDelete` (REST endpoints)
2. Extract all `global` or `public` method signatures (return type, method name, parameters)
3. Note if class extends another class or implements an interface

**Efficient approach:** First batch grep to find annotated methods:
```bash
grep -rn "@AuraEnabled\|@InvocableMethod\|@RemoteAction\|@Http" --include="*.cls" [classes-path]
```
Then deep-read only classes with customer-facing methods.
