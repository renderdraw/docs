  <name>Task 1: Parse SUMMARY.md and classify all documentation pages</name>
  <files>.planning/phases/01-audit-gap-analysis/docs-inventory.md</files>
  <action>
Parse `docs/SUMMARY.md` to extract every page path and title. For each page:
1. Check if the file exists and has content beyond just a heading (more than 2 non-empty lines)
2. Classify as: `has-content`, `empty-stub` (exists but heading-only), `index` (README.md section index), or `missing` (in SUMMARY.md but file doesn't exist)
3. Tag each page with its section: About, Introduction, Usage-Scenarios-2D, Usage-Scenarios-3D, API-Documentation, Digital-Twin, CAD-Conversion, Diving-Deeper, Other

Write results to `docs-inventory.md` as a markdown table with columns:
| Section | Page Path | Title | Status | Lines |

Group by section. Include total counts at the top: X has-content, Y empty-stub, Z index, W missing.

**How to check content:** Use `wc -l` and `head -5` on each file. A file with ≤3 lines where line 1 is `#` or `---` is an empty stub. README.md files are indexes.
  </action>
