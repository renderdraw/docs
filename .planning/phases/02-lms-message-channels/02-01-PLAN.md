- Publishers/subscribers (from source-lms-events.md):
  - `Canvas_Interaction` — publishers: `canvas3D`, `standalone_DataTable` · subscribers: `canvas3D`, `canvas2D`
  - `Canvas_Initialized` — publishers: `canvas3D`, `canvas2D` · subscribers: `standalone_DataTable`

  - `Canvas_ElementHovered` — publishers: `canvas3D`, `canvas2D` · subscribers: `standalone_DataTable`

- `canvas-element-hovered.md` currently claims the channel is "primarily used for 2D canvas interactions" — source shows publishers are both `canvas3D` and `canvas2D`. This is a verification correction.
