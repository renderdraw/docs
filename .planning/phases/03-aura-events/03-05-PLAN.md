# Events (Aura)

RenderDraw raises Aura application events to notify consuming components of renderer state changes, user interactions, admin workflow transitions, and scene lifecycle moments. All 33 public events are APPLICATION type — any component in the same Salesforce org can register an `aura:handler` for them.

## How to Handle a RenderDraw Aura Event

\`\`\`xml
<aura:component implements="flexipage:availableForAllPageTypes,force:hasRecordId">
  <aura:handler event="RDraw:EVT_Renderer_Loaded" action="{!c.handleRendererLoaded}" />
  <RDraw:AdvancedRenderer aura:id="renderer" recordId="{!v.recordId}" />
</aura:component>
\`\`\`

Handler registration requires the fully-namespaced event name `RDraw:EVT_<Name>`. See each event page for the exact handler snippet and payload details.

## Access Levels

- **global** (14 events) — accessible across namespaces. The primary public API surface.
- **public** (1 event: `EVT_Renderer_Input`) — accessible within the declaring namespace.
- **default** (18 events) — accessible within the managed-package namespace; documented here for partners who work within the RDraw namespace boundary.
