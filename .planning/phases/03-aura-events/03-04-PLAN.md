**Semantic hints for Usage Notes (factual — do not invent behaviors):**

- **Admin events** — all fire within the AdminTestRenderer admin UI for defining test scenes, explosions, and groups. Handlers are in the admin UI components themselves. External consumers are not expected; these are visible because they share the Aura event namespace.
- **Layout events** — fire from AdvancedLayout to request showing/hiding the context-detail header chrome. Consumers: any component embedding AdvancedLayout.
- **Scene event** — fires when scene settings are ready to be persisted (consumer's callback is invoked after the save completes).
- **Interaction event** — fires to log status messages from inside interaction handlers; `severity` maps to log levels (0=log, 1=info, 2=warn, 3=error — verify against InteractionEvent controller if possible).
- **Add3DShape** — fires to request that a 3D shape be added to the scene. Consumers are typically the renderer component.
- **Switch_Tab** — fires from tab-navigation UI to request switching the active tab. Consumers: tab-container components.
